Home Assistant token not found.
Quickest fix (recommended):
  1. In HA, click your profile → Security → "Long-Lived Access Tokens" → Create Token.
  2. Copy the token.
  3. Open the Homelab Inventory add-on page → Configuration tab → paste into ha_token → Save.
  4. Stop + start the add-on.
If you also want to hit HA over the LAN (not through Supervisor's proxy), set ha_base_url to e.g. http://homeassistant.local:8123 in the same Configuration tab.
